# Muath Alsuraihi

تطبيق iOS لتلاوات الشيخ معاذ بن ماجد السريحي، بدون إعلانات وبدون تتبع.

## IPA الحالي

ينشئ GitHub Actions ملف IPA غير موقّع باسم
`MuathAlsuraihi-unsigned.ipa`.

هذا الملف مناسب للتثبيت اليدوي عبر AltStore أو Sideloadly فقط. لا يمكن رفعه
إلى TestFlight أو App Store كما هو، لأنهما يتطلبان حساب Apple Developer
وشهادة توزيع وملف توقيع صالحين.

لا تحفظ شهادات Apple أو كلمات المرور أو أي مفاتيح خاصة في المستودع.

## الصوت والمستودع

ملفات التلاوات الأصلية لا تُحوَّل ولا تُضغط داخل هذا المشروع. تحفظ النسخ
الاحتياطية خارج Git، وتُقدَّم ملفات البث والتنزيل من التخزين المخصص لها.

إذا كان هذا المستودع عامًا، فيجب جعله خاصًا قبل النشر؛ قد يحتوي تاريخ Git
القديم على ملفات صوت كبيرة لا ينبغي إتاحتها للعامة. تنظيف تاريخ Git عملية
حساسة تؤجل إلى قرار منفصل، ولا تُنفذ من دون نسخة احتياطية وموافقة صريحة.

لا تُحفظ مفاتيح التخزين أو أي أسرار في Git، حتى لو كان المستودع خاصًا.
